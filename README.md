# Skardu Faculty Kickoff Webpage

A clean, information-focused web page introducing the Skardu Scale-Up Fellowship to faculty.

## Live URL

**Visit:** https://usmanjaved-droid.github.io/skardu-faculty-kickoff/

Share this link with faculty for the kickoff call.

## What's Included

- Program overview and vision
- Profiles of all 11 fellows (social entrepreneurs)
- Faculty roles and expectations
- Complete day-by-day program timeline (7-day intensive retreat)
- Engagement activities (cultural night, fireside chat, demo day, etc.)
- Logistics and preparation checklist
- Next steps and action items

## Tech Stack

- HTML5
- CSS3 (responsive design with 768px mobile breakpoint)
- Vanilla JavaScript (data-driven component rendering)
- GitHub Pages (deployment)

## Local Development

To run locally:

```bash
cd skardu-faculty-kickoff
python3 -m http.server 8000
# Then visit http://localhost:8000
```

Or use any local server (Node, VSCode Live Server, etc.)

## Updates & Changes

To update content:

1. Edit `index.html` for structure
2. Edit `styles.css` for styling
3. Edit `script.js` for data and interactivity
4. Commit: `git add . && git commit -m "message"`
5. Push: `git push origin main`
6. GitHub Pages auto-deploys on push (takes 1-2 minutes)
